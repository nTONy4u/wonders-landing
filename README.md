# Wonders - Alpine Bus Journeys

## Описание проекта

Адаптивный лендинг для сервиса поиска автобусных билетов в Альпах.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript

## Функционал

- Адаптивная вёрстка под 1440px, 768px, 360px
- Форма поиска с выбором типа поездки (Round trip / One Way)
- Счётчик пассажиров (от 1 до 12)
- Календарь для выбора дат с ограничениями (нельзя выбрать прошлое)
- Автодополнение станций из списка альпийских городов
- Валидация формы (заполнение полей, станции не совпадают, корректные даты)
- Бургер-меню с анимацией для мобильных устройств
- Модальные окна для ошибок валидации
- Сохранение данных поиска и переход на страницу результатов
- Галерея изображений
- FAQ с раскрывающимися ответами
- Блок контактов с карточкой поверх футера
