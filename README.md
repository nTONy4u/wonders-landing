# Wonders - Alpine Bus Journeys

## Описание проекта

Адаптивный лендинг для сервиса поиска автобусных билетов в Альпах.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (2 часть)


## Текущий статус (Часть 1)

**Реализовано:**

- HTML структура всех секций
- CSS стили с адаптивом под 1440px, 768px, 360px
- Бургер-меню (базовая стилизация)
- Форма поиска
- Секция статистики
- Секция галереи
- Секция FAQ (работает через details/summary)
- Секция с приложениями
- Блок контактов
- Футер
